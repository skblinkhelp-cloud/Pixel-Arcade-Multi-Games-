# MultiGame Arcade 🕹️

**MultiGame Arcade** is an Android retro gaming arcade launcher featuring 8 games:

1. **Pixel Moto Rider** (2D Racing)
2. **Farm Jigsaw Puzzle** (16-bit Puzzle)
3. **Jump Quest** (Platformer)
4. **Pixel Car Rush** (Speed Racing)
5. **Space Blast** (Space Action Shooter)
6. **Speed Jump** (Endless Jump)
7. **Puzzle Pop** (Arcade Puzzle)
8. **Pixel Snake Arcade** (Retro 8-Bit Snake)

---

## 📱 App Specs
- **Package Name (Application ID):** `com.sk.multigamearcade`
- **Min SDK:** `26` (Android 8.0)
- **Target SDK:** `37`
- **Build System:** Gradle (Kotlin DSL)
- **UI Toolkit:** Jetpack Compose + XML Views + WebView Assets

## 🛠️ Build & Run
To assemble a debug APK:
```bash
./gradlew app:assembleDebug
```

To assemble a release Bundle for Google Play Console:
```bash
./gradlew app:bundleRelease
```
